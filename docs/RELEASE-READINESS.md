# Release readiness — rc.3

**Suitable now:** publish the source as an open-source reference candidate; demonstrate a fictional provider; request an engineering pilot. No remote publication has been performed.

**Implemented:** no tempLogin account in the default flow; TV/phone handoff; provider identity interface; explicit duration; transactional single-use exchange; provider-scoped session guard; per-session revocation; production demo block; SDK build/types; HTTP spec; tests; partner brief and email drafts.

**Required before a real service pilot:** actual provider authentication adapter and phone login navigation; entitlement integration; one compatible TV app; guarded playback and bounded licences; production SQL topology; secrets and operational ownership; private disclosure channel; physical iPhone/Android/TV tests and security review.

**Required before a stable production claim:** independent review, deployment/restore drill, realistic load and abuse testing, accessibility review, agreed media/offline semantics, threat-model findings resolved, reproducible release/provenance and a supported maintenance policy.

**Not supplied:** official Netflix/YouTube/Disney+ integration, private APIs, commercial partnership, permission to bypass service policies, or a universal login credential. A provider's engineering work and approval remain necessary.

Legacy wallet/hospitality tests remain for regression coverage only; their results do not prove the new provider integration. Consult the current validation record for the actual new-flow evidence.
