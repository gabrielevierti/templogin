# Security policy
This is a release candidate, not an independently audited identity service. Use synthetic data while evaluating it. The maintainer has not yet configured a disclosure contact or public repository. Before publishing, enable GitHub private vulnerability reporting and document the final reporting URL here. Do not publish exploitable findings in public issues; contact the repository owner privately through its verified security channel once established. No response-time SLA is promised.

Supported version: the latest 1.0.0-rc candidate only, until a stable support policy is adopted. The threat model and verification record describe tested controls and remaining release gates. We do not claim SOC 2, ISO 27001, penetration testing, or resistance to a compromised endpoint.
